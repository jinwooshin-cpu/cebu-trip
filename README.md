# 🌴 세부 가족여행 앱 (2026.11.24 ~ 11.28, 3박 5일)

핸드폰에서 앱처럼 열리는 여행 일정표입니다. (일정 · 준비물 · 맛집/쇼핑 · 항공/숙소 정보)

## 내용 고치기 (와이프용)

**고칠 파일은 `trip-data.js` 하나뿐입니다.**

1. 저장소에서 `trip-data.js` 클릭
2. 오른쪽 위 ✏️ 연필 버튼
3. 글자만 고치기 — 따옴표(`"`)와 쉼표(`,`)는 지우지 않기
4. **Commit changes** → 1~2분 뒤 앱에 반영

일정 한 줄은 이런 모양입니다.

    {"time": "09:00 ~ 09:30", "title": "호핑투어 로비에서 만나기", "note": "준비물: 선크림,비치타월"}

- **날짜를 바꾸려면** 맨 위 `"start"`(여행 첫날)만 고치면 일정의 날짜·요일·D-day가 모두 자동으로 바뀝니다.
- 항공편 날짜는 `"depDate": "2026-11-24"` 처럼 `연-월-일` 형식으로 적습니다.
- 항공 예약번호는 `"code": ""` 안에 넣으면 정보 탭에 표시됩니다.
- 줄을 새로 넣으려면 기존 줄을 복사해서 붙이고 쉼표만 맞추면 됩니다.

## 앱처럼 열어두기 (처음 한 번만)

1. 저장소 **Settings → Pages → Branch: main / (root) → Save**
2. 잠시 뒤 나오는 주소(`https://아이디.github.io/저장소이름/`)를 핸드폰에서 열기
3. 아이폰: 공유 버튼 → **홈 화면에 추가** / 안드로이드: 메뉴 → **홈 화면에 추가**

한 번 열어두면 해외에서 데이터가 없어도 마지막으로 본 내용이 열립니다.

## 참고

- 준비물 체크는 각자 핸드폰에만 저장됩니다. (서로 공유되지 않아요)
- 상단 스위치로 체험형 / 호캉스형을 바꿔볼 수 있습니다.
