# 🌴 세부 가족여행 앱 (2026.11.24 ~ 11.28, 3박 5일)

핸드폰에서 앱처럼 열리는 여행 일정표입니다. (일정 · 준비물 · 맛집/쇼핑 · 항공/숙소 정보)

## 내용 고치기 (앱 안에서 바로)

1. 앱 오른쪽 위 ✏️ 버튼을 누릅니다
2. 시간·일정·메모·준비물을 눌러 글자를 바로 고칩니다 (＋ 추가 / ↑↓ 순서 바꾸기 / 삭제 가능)
3. 다 고치면 **완료** 버튼을 누릅니다 — 고치는 즉시 자동 저장돼 두 사람 폰에 함께 반영됩니다

- 날짜를 바꾸려면 ✏️ → **정보** 탭 → "여행 첫날"만 고치면 일정의 날짜·요일·D-day가 모두 바뀝니다.
- 잘못 고쳤다면 ✏️ → 정보 탭 맨 아래 "처음 상태로 되돌리기"로 처음 일정표로 돌아갈 수 있습니다.
- 준비물 체크는 각자 폰에만 저장됩니다.

## 앱처럼 열어두기 (처음 한 번만)

아이폰: 공유 버튼 → **홈 화면에 추가** / 안드로이드: 메뉴 → **홈 화면에 추가**
한 번 열어두면 해외에서 데이터가 없어도 마지막으로 본 내용이 열립니다.

## 관리자용 메모

- `trip-data.js` 의 `"syncUrl"` 에 공유 저장소(Firebase Realtime Database) 주소를 넣으면 두 사람의 수정이 서로 반영됩니다. 비워두면 수정 내용은 그 폰에만 저장됩니다.
- `trip-data.js` 의 나머지 내용은 "처음 상태"(기본 일정표)입니다.
